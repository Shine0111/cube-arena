# CUBE ARENA — Next.js

A responsive Next.js + TypeScript starting point for the CUBE ARENA multiplayer speedcubing project. The dashboard layout follows the supplied `DESIGN.md` and the home dashboard `code.html` as visual references.

## Included

- Next.js App Router, TypeScript, Tailwind CSS configuration
- Responsive dashboard with the Obsidian Kinetic design tokens
- Header navigation and starter interactions for room setup/code entry
- Original supplied HTML designs and `DESIGN.md` retained under `design-reference/`
- Routes listed in `PROJECT_STRUCTURE.md` are scaffolded with placeholder pages

## Run locally

1. Install Node.js 18.17+ (Node 20 LTS recommended).
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.
